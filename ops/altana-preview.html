The six faces, and when each one appears

States

Motion here is transform and opacity only, so the compositor does the work and nothing repaints. Animation pauses when the tab is hidden, and collapses to a plain fade if the operating system is set to reduce motion. The dot is mounted on <body> so no transformed ancestor can capture it, and it clears the mobile dock below 1180px.

The conversation

Click the dot to open the panel. /altana/ask is mocked below (no server, no keys, no real model call) so the whole loop is exercisable here: type settings to see a clientActions batch, delete to see the confirm round-trip, slow to see a fallback notice plus a blocked tool, or fail to see the honest error path.
